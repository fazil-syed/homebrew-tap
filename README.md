# fazil-syed/homebrew-tap

`brew install` casks maintained by Syed Fazil.

| Cask | What it does |
|---|---|
| `todoer` | Easy CLI task manager with groups and tasks |
| `kindle-widget` | macOS desktop widget showing live Kindle reading progress |

## Install

```sh
brew tap fazil-syed/homebrew-tap
brew install --cask fazil-syed/homebrew-tap/todoer
brew install --cask fazil-syed/homebrew-tap/kindle-widget
```
